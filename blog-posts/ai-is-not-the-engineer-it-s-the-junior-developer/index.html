AI Development · Engineering practice

The engineers who get the most out of AI are the ones who stay in charge of the architecture, the rules, and what happens when things go wrong.

Nathan Tebay · May 2026

A lot of people treat AI like it's the engineer, and the human just signs off at the end.

That's not how I use it.

For me, AI is more like a junior developer. I set the boundaries. I'm still the one responsible for the architecture, the rules, how things get checked, and what happens if something goes wrong.

Here's how that looks in my multi-agent coding setup.

The hard rules were explicit:

  • AI never writes to disk without approval.
  • Unsafe patterns are blocked before review.
  • Confidence thresholds determine escalation.
  • Revision loops are bounded.
  • Security-sensitive work is never delegated.

Those rules didn't come from AI. I set them.

I took the same approach in QMK Nexus.

A lot of my architecture choices went against what AI usually suggests for AWS projects.

  • S3 instead of DynamoDB for keyboard indexing
  • Per-user SQLite databases stored in S3
  • ECS Fargate instead of Lambda for firmware builds
  • A custom Python firmware generation pipeline instead of wrapping the QMK CLI

I made those calls because I know what firmware generation actually looks like in practice, what compilers need, and what will be maintainable over time.

AI helped me build it, but the decisions were mine.

The real difference shows up in validation.

AI can write code from a spec, but it can't plug firmware into real hardware, notice that RP2040 builds fail differently than Teensy, track the problem down to board definitions, and fix the pipeline.

That's still my job.

I don't see AI replacing engineering judgment. What it does is give you more leverage, if you know your system well enough to set limits, guide the work, check it, and throw out what doesn't fit.

The value isn't in taking AI code at face value.

The value is in building systems where you can actually trust the generated code to run safely.
