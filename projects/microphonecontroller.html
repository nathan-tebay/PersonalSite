MicrophoneController

2-button USB HID microphone controller with tap-to-toggle and push-to-talk

View on GitHub

Overview

This project began as a way to control multiple microphone channels in games and communication apps, such as team and proximity chat. The controller uses two buttons so you can either push-to-talk or tap-to-toggle without guessing whether a channel is active. The bottom mode switch changes the device between keyboard and gamepad HID output depending on which type the app supports.

Today I mainly use it with my WhisperTranscription application. The dual buttons and tap-or-hold behavior make it easy to distinguish between transcribing text and sending commands to an AI model. I may eventually make the hotkeys configurable over WebUSB, but for now the current setup works well. Since WebUSB depends on an external application, I am considering hosting the software in Lambda alongside this site.

Stack

Arduino C++ ATmega32U4 USB HID AVR core arduino-cli

Challenges

  • As a keyboard HID, the device interfered with controller input detection in games.
  • AI-generated hold-or-toggle implementation didn't work as intended — rewrote it manually.

Learnings

  • Simpler model wins: a single toggle state is cleaner than separate latch and hold logic.
  • The mode switch changes which USB interface sends input — the device doesn't reinitialize.

Hardware

  • Board: nullbits Bit-C PRO (Arduino Leonardo-compatible)
  • Button 1 — D2, internal pull-up → GND
  • Button 2 — D3, internal pull-up → GND
  • LED 1 — D4 via 220 Ω resistor
  • LED 2 — D5 via 220 Ω resistor
  • Mode switch — D15 to GND = keyboard; floating = gamepad

Button Behaviour

  • Tap — toggle mic on/off (keyboard: key press+release; gamepad: brief button press)
  • Hold ≥ 50 ms — push-to-talk; latch active while held, cleared on release
  • Mode switch — releases all outputs and resets all latch states
  • Keyboard keys: Scroll Lock (btn 1), Pause (btn 2)
  • Gamepad buttons: 8 and 9 (beyond standard controller layouts)
